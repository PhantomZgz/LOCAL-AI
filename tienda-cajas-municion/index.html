Preguntas frecuentes

¿Vale para otros calibres?

Esta versión está pensada para 9×19. Cartuchos como .380 ACP entran pero quedan sueltos. Si hay demanda podemos preparar versiones para .45 ACP, .40 S&W o .22 LR.

¿Venden munición?

No. Solo vendemos la caja de almacenamiento vacía. La caja no contiene ni incluye cartuchos.

¿Puedo pedir un color que no aparece?

Sí. Escríbenos con el color y la cantidad. Para pedidos de 10 cajas o más el color personalizado no tiene recargo.

¿Hacen grabado o logotipo?

Podemos imprimir texto en relieve en la tapa, por ejemplo el nombre de tu club. Pídenos presupuesto.
